# خطوط پروکسی و Xray مدیریت‌شده

نصب‌کننده Xray Core نسخهٔ 26.11.9 را با SHA-256 ثابت در `/opt/tunnelmgr/bin/xray` نصب می‌کند. این نسخه و سرویس `tunnelmgr-xray.service` از Xray یا x-ui موجود جدا هستند. نصب‌کننده فایل‌های اجرایی، تنظیمات و واحدهای سرویس آن‌ها را جایگزین، خاموش یا بازنویسی نمی‌کند.

در به‌روزرسانی یک سرور از پنل، نسخهٔ Core مدیریت‌شده از سرور مرکزی داخل بستهٔ SSH فرستاده می‌شود؛ در نتیجه مقصد برای نصب به GitHub دسترسی لازم ندارد. نصب مستقل، Core را مستقیماً از انتشار رسمی Xray دریافت و آرشیو و فایل اجرایی را با checksum ثابت بررسی می‌کند.

پیش از اعمال فوروارد، پورت‌های TCP و UDP روی IPv4 و IPv6 با listenerهای سیستم و پورت‌های منتشرشدهٔ Docker مقایسه می‌شوند. اگر آدرس درخواستی wildcard باشد، listenerهای همان خانواده نیز در نظر گرفته می‌شوند. listener متعلق به سرویس `tunnelmgr-xray` هنگام جایگزینی تنظیمات خودش مستثنا است. تداخل باعث رد درخواست با آدرس، پورت و در صورت امکان نام فرایند یا container مالک می‌شود. اگر listener پس از بررسی و پیش از راه‌اندازی ایجاد شود، شکست bind باعث بازگردانی تنظیمات قبلی می‌شود؛ سرویس دیگر متوقف نمی‌شود.

این نصب، مسیر پیش‌فرض شبکه و تنظیمات Xray/x-ui دیگری را تغییر نمی‌دهد. برای اجرای هم‌زمان دو Core، پورت و IP شنودشان باید جدا باشد.
